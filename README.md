# Easy Snapshot Generator Addon

This addon contains a **SnapshotGenerator** class which can easily generate snapshots of 2D elements at runtime, storing them into an atlas texture.

## Installation

1. Install the [easy compositor addon](https://github.com/sphynx-owner/Easy-Compositor-Addon).

2. Download the latest release, and move the contents of `addons` into your project's addons folder.
